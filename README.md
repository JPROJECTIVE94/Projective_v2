# Projective Finance — website

Static single-page site. No build step.

## Files

- `index.html` — all page content and sections (hero, Projective OS, the pinned Upload/Verify/Funded flow, Why Projective with pool snapshot, Global access, FAQ, partners, CTA, footer). Section layout values are inline, as exported from the design.
- `styles.css` — shared styles: buttons, eyebrow dots, FAQ rows, `.wrap` gutter, responsive rules (`@media (max-width:900px)`).
- `case-study.html` — Econergy / Illinois schools case study, linked from the "Case study" nav item on every page. Bracketed values ([$25M], [2 wks], [25 year], the testimonial, the COD date) are placeholders carried over from the source draft; confirm or replace before launch.
- `404.html` — the not found page: the rabbit mark upside down on navy, nothing else; it links home. Point your host's 404 rule at it.
- `contact.html` — contact page (split layout, form). The form validates in the browser and then opens the visitor's mail client addressed to hello@projective.finance with the fields filled in; swap the submit handler in `script.js` for Formspree, HubSpot or your CRM endpoint when one exists.
- `script.js` — flow section, pool snapshot tabs, contact form.
- `assets/` — Projective logo and partner logos (Avalanche, Goodlynx, Econergy, Insomnia).

## Run locally

```
python3 -m http.server 8000
```
then open http://localhost:8000.

## Things to set before launch

- Launch buttons point at `https://www.projective.finance/` (placeholder). Search-and-replace that URL with the app URL.
- Contact: the closing CTA uses `mailto:hello@projective.finance`; the footer Telegram icon has no link yet.
- FAQ answers in `index.html` are drafts.
- Brand colours: navy `#09133A`, accent `#D9A32B` (alternate `#FFB726`). Search-and-replace in `index.html` and `styles.css`.

## Upload. Verify. Funded. (pinned flow)

The `#flow` section pins a full-height frame for about 2.4 screens of scrolling and slides three panels sideways as you scroll; the tab pill at top right shows the active step and can be clicked to jump. Below 900px it becomes a plain stacked list. The three isometric drawings are inline SVG generated by a script (ask for `build_flow.py` if you need to regenerate them); the figures on the tags and live panels are illustrative samples.

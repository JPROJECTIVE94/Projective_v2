# Projective Finance — website

Static single-page site. No build step.

## Files

- `index.html` — all page content and sections (hero, Projective OS, the pinned Submit documents / Underwriting / Funding flow, Why Projective with pool snapshot, Global access, FAQ, partners, CTA, footer). Section layout values are inline, as exported from the design.
- `styles.css` — shared styles: buttons, eyebrow dots, FAQ rows, `.wrap` gutter, responsive rules (`@media (max-width:900px)`).
- `case-study.html` — Econergy / Illinois schools case study, linked from the "Case study" nav item on every page. Bracketed values ([$25M], [2 wks], [25 year], the testimonial, the COD date) are placeholders carried over from the source draft; confirm or replace before launch.
- `404.html` — the not found page: the rabbit mark upside down on navy, nothing else; it links home. Point your host's 404 rule at it.
- `contact.html` — contact page. The form asks for the visitor's role first (Builder, Investor, Municipality, Other) and shows only that role's fields; `?role=investor` or `?role=builder` preselects it and `?facility=` preselects a facility. Set `FORM_ENDPOINT` at the top of the contact block in `script.js` to a Formspree, HubSpot or CRM URL and submissions (including files) POST there; until then the form opens the visitor's email client.
- `script.js` — flow section, pool snapshot tabs, contact form.
- `assets/` — Projective logo and partner logos (Avalanche, Goodlynx, Econergy, Insomnia).

## Run locally

```
python3 -m http.server 8000
```
then open http://localhost:8000.

- Brand colours: navy `#09133A`, accent `#D9A32B` (alternate `#FFB726`). Search-and-replace in `index.html` and `styles.css`.

## How a project gets financed (pinned flow)

The `#flow` section pins a full-height frame for about 1.9 screens of scrolling and slides three panels sideways as you scroll; the tab pill at top right shows the active step and can be clicked to jump. Below 900px it becomes a plain stacked list. The three isometric drawings are inline SVG generated by a script (ask for `build_flow.py` if you need to regenerate them); the figures on the tags and live panels are illustrative samples.
